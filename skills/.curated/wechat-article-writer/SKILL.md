# 公众号文章写作流程

5 步完成高质量公众号文章：搜索资料 → 撰写文章 → 生成标题 → 排版优化 → 质量检查

## Step 1: 搜索资料

使用 websearch 工具搜索主题相关资料：

搜索要求：

1. 并行搜索多个来源（官方数据、行业报告、权威媒体）
2. 优先获取最新资料（当月/当季，中国数据优先）
3. 可使用 `task(subagent_type="explore", run_in_background=true, ...)` 并行搜索
4. 深度总结搜索结果，提取关键数据和案例
5. 记录每条数据的来源机构/媒体名称，后续标注出处用

## Step 2: 撰写文章

撰写要求：

- 1000-1500 字
- 故事化开头，带情感色彩（兴奋/焦虑/好奇）
- 使用中国语境案例和数据
- 结构：效果展示 → 问题描述 → 步骤教学 → 升华总结
- 段落控制在 3-5 行，重要数据单独成段加粗

## Step 3: 生成标题

生成 5 个爆款标题，特点：

- **痛点明确**：直击读者痛处
- **数字吸引**：具体数字更有说服力
- **结果导向**：承诺具体收益
- **情绪调动**：惊讶、神技、秘籍等词汇
- **悬念设置**：引发好奇心

## Step 4: 排版优化

优化建议：

1. **段落结构**：每段 3-5 行，重要数据单独成段加粗
2. **配图位置**：标题下方封面图、章节过渡处插图、结尾总结图
3. **金句**：单独成段，增强记忆点
4. **互动引导**：文末加一句面向读者的提问或行动号召

## Step 5: 质量检查（三步骤）

文章初稿完成后，按以下三步逐一检查，确保达到发布标准。

### 5.1 所有引用给出明确出处

每条数据、引用、观点都必须在文中标注来源机构名称。

格式：`**数据**` + 来源机构说明

示例：

```
2026年，中国高校毕业生预计 **1270万**，再创历史新高。
```

↓ 改为

```
2026年，中国高校毕业生预计 **1270万**（人社部/教育部数据），再创历史新高。
```

### 5.2 引用以带描述的 Markdown 外链形式嵌入

每条出处必须是可点击的链接，且链接带有悬停描述（title 属性）。

格式：

```markdown
[链接文字](URL "来源描述")
```

- `URL` — 来源页面的完整链接
- `'来源描述'` — 悬停时显示的简短说明，必须包含来源机构/媒体名称 + 内容摘要
- 链接放在数据/引用文字上，不要单独成行
- 优先使用原始来源链接，次选权威媒体转载

不同场景的格式示例：

| 场景     | 示例                                                                       |
| -------- | -------------------------------------------------------------------------- |
| 官方数据 | `[1270万](http://... '人社部：2026届高校毕业生规模预计1270万人')`          |
| 行业报告 | `[7.8万元](http://... '猎聘《2025年度人才供需趋势报告》')`                 |
| 媒体报道 | `[98人抢1岗](http://... '腾讯新闻：2026届高校毕业生就业新选择')`           |
| 国际机构 | `[22%就业变革](http://... '世界经济论坛：到2030年预计新增7800万就业机会')` |
| 期刊杂志 | `["学历崇拜降温"](http://... '《财经》杂志：学历崇拜降温')`                |

### 5.3 添加符合文章语境的题图和插图

使用 Unsplash 搜索配图，skill 脚本路径：`.agents/skills/unsplash/scripts/search.sh`

**数量建议：**

- 公众号文章一般 **3张图**（1张题图 + 2张内插图）
- 每 500-800 字一张插图

**选图原则：**

- **题图（封面）**：必须切合文章核心主题
  - 中国语境文章 → 人物/场景必须是中国或亚洲面孔或场景
  - 避免外国毕业照、外国街景等不符合读者预期的图片

- **内插图**：放在章节过渡处，帮助读者"换气"
  - 可以使用不显示人物的场景图（书架、办公桌、城市天际线等）

- **图片 Markdown 格式**：

  ```markdown
  ![描述文字](图片URL "悬停文字")

  _摄影：摄影师名，来自 Unsplash_
  ```

- **Unsplash 追踪**：图片确认使用后执行 track.sh
  ```bash
  .agents/skills/unsplash/scripts/track.sh PHOTO_ID
  ```

## 完整检查清单

发布前逐一核对：

- [ ] 资料已搜索（Step 1）
- [ ] 文章已撰写（Step 2）
- [ ] 标题已生成（Step 3）
- [ ] 排版已优化（Step 4）
- [ ] 每条数据都有出处标注（Step 5.1）
- [ ] 出处以 Markdown 外链形式嵌入，带描述（Step 5.2）
- [ ] 链接描述包含来源 + 摘要
- [ ] 有题图（封面），符合语境（Step 5.3）
- [ ] 有内插图（至少 1-2 张），有署名
- [ ] 中国语境文章，图片无外国场景违和
- [ ] Unsplash 图片已执行 track.sh 追踪
